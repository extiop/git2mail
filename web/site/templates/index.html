Find the email addresses behind any GitHub repository or profile

You give it a GitHub repository or a profile, and it lists the email addresses the developers left in their commits (the changes they published) - read straight from GitHub's public interface, in your browser. Free, no account, nothing stored here.

Try an example: octocat/Hello-World a whole profile

The scan runs in your browser: GitHub receives the requests from your IP address and sees every query. If you are signed in to GitHub in this browser, GitHub can link these requests to your account. The repository's traffic graph counts page views and clones, not API calls, so the scan itself will not show up there. GitHub limits anonymous visitors to about 60 requests per hour. The number you have left appears below once the scan starts.

Read this before acting on a result

  • These addresses come from the information stored inside public commits, and that information can be old or faked: an address in a commit proves nothing about who owns the mailbox (data quality).
  • Not everyone appears here: when a project folds several changes into one merge, some names never show up. A repository scan reads the default branch - the project's main line - not every branch.
  • A profile scan reads GitHub's public events timeline, which only keeps recent activity.
